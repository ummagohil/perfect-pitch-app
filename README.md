# 🎤 Perfect Pitch
Test, record and upload clips to see if you've got perfect pitch.

### 📋 Aims of App

- User can upload a file and it parses to test for pitch
- User can take the perfect pitch test and get a result from app
- User can paste a link in and see if there is perfect pitch within the clip
- User can record a clip and get a result from app 

### 👩‍💻 Technical Details

- React
- Python
